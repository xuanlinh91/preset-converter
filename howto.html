How to convert preset?





1. Convert from a camera raw preset to a lightroom preset


- Visit the site, click on the file chooser, select a camera raw preset, which is a file of the form: name preset.xmp.

- Click the convert button, the preset file is converted to the lighroom preset and the zip archive will be automatically downloaded.

- Using winrar or winzip or 7zip to extract the downloaded zip file, you will see the preset has been converted.




2. Convert from a Lightroom preset to a Camera Raw preset


- Visit the website, click the file select button, select a preset of the lightroom, it is a file named: preset.lrtemplate name,
the template of the lighroom is usually saved in the folder C: \ Users \ Administrator \ AppData \ Roaming \ Adobe \ Lightroom \ Develop Presets \ User Presets

- Click the convert button, preset file is converted to preset format of camera raw and the zip archive will be automatically downloaded.

- Use winrar or winzip or 7zip to extract the downloaded zip file, you will see the preset file has been converted.

1. Chuyển preset camera raw sang preset lightroom


Truy cập website, click nút chọn tệp, chọn 1 preset của camera raw, đó là 1 file có dạng: tên preset.xmp

- Click nút convert, file preset được convert sang định dạng preset của lighroom và sẽ tự động tải về dưới dạng file nén zip

- Dùng winrar hoặc winzip hoặc 7zip để giải nén file zip vừa tải về, sẽ thấy file preset đã dược convert




2. Chuyển preset lightroom sang preset camera raw


Truy cập website, click nút chọn tệp, chọn 1 preset của lightroom, đó là 1 file có dạng: tên preset.lrtemplate, các template của lighroom thường được lưu
trong thư mục C:\Users\Administrator\AppData\Roaming\Adobe\Lightroom\Develop Presets\User Presets

- Click nút convert, file preset được convert sang định dạng preset của camera raw và sẽ tự động tải về dưới dạng file nén zip

- Dùng winrar hoặc winzip hoặc 7zip để giải nén file zip vừa tải về, sẽ thấy file preset đã dược convert
